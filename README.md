<h1 align="center">Crypto by Team Jamong</h1>

### 주의사항
**Team Jamong(이하 '당사')는 Crypto(이하 '서비스')를 제공하기에 앞서 아래 사항을 공지합니다.**

1. 당사의 서비스는 **어떠한 보증 및 책임도 없이 제한된 사용자에 한해서만** 제공됩니다.
2. 당사의 서비스를 악용할 경우 발생하는 **그 어떠한 피해도 당사가 책임지지 않습니다.**
3. 당사의 서비스가 제공하는 일체의 정보에 대한 **일체의 유출을 엄금하며,** 이로 인해 발생하는 **그 어떠한 피해도 당사가 책임지지 않습니다.** 이는 당사의 서비스가 제공하는 **모든 정보, 문서, 첨부파일 등을 포함**하지만 이에 국한되지 않습니다.
4. 당사의 서비스의 존재를 제외한 **그 어떠한 사항도 일체의 발설을 금하며,** 이를 위반한 경우 **법적 문제가 발생할 가능성이 있습니다.**

**당사의 서비스는 제한된 사용자에게만 연구 및 교육 목적으로 공개되며, 위 사항을 준수하지 않을 경우 모든 서비스를 중단할 예정입니다.**

### 서비스 소개
Crypto는 AES-256을 통해 이중 암호화를 진행하는 서비스입니다. (Plain Text - Public Key - Main Key)

### 서비스 사용 방법
1. `npm install`로 패키지를 받습니다.
2. Windows 환경에서는 `node main.js` 명령어를 입력하고, Linux 환경에서는 `screen -s Crypto node.js` 명령어를 입력하여 프로그램을 실행합니다.

### 일러두기
1. 해당 레포지토리는 **외부로 공개할 수 없으며,** 이를 위반할 경우 **법적인 책임을 묻겠습니다.**
